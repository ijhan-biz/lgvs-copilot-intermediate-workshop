선택형 도움 사다리 — 필요한 파일만 열기
======================================
먼저 계약에서 기대값을 직접 적고 시도·예측을 저장한 뒤 한 단계만 선택한다.
0. hints/0-environment.txt — 폴더와 실행 환경
1. hints/1-review-target.txt — 검토 대상과 준비 상태
2. hints/2-counterexample.txt — 작은 반례를 만드는 질문
3. hints/3-comparison.txt — 내 가설을 검토하는 질문
4. 완전한 복구 해설은 학습자 파일에 없다. 직접 시도/고정과 본인 재현 뒤
   17:25 이후 공개 조건을 마치고 강사에게 참고 답안 비교를 요청한다.
보충: hints/js-reference.txt — 문제와 성공 기준 09:30–09:40 시연 중 JS/test 브리지5분.
문제와 성공 기준 첫 편집 전 baseline→본인 정확한 반복 기록 검사, 계획과 검증 기준 단계의 기준선 확인/계획만,
요구 변경과 구현 기존 검사 재실행→승인 후 timed_out/not_run 후보 검사(v1 RED/v2 GREEN),
결과와 기준 검증 C6 입력 비변경·새 후보 배열·첫 원본 행 참조 검사 순서다. 제공1+본인3=4개다.
수정과 재검증 시간: 16:20–28 재현/가설8, 16:28–38 최소 복구/review16 확인10,
16:38–45 독립 전이7, 16:45–50 src v2/learner 회귀·기록5분.
수정과 재검증 독립 전이: 본인 예측·이유·expectedIds 저장/동결과 최초 명령의 실제 outcome(pass/fail/unknown)·exit·출력 저장/동결을 모두 마칠 때까지 AI·힌트·강사 도움·답안·고급 모델을 닫는다.
미실행/실행 불가는 outcome unknown·exit null로 동결하고 incomplete/HOLD를 남긴 뒤 과정 도움을 연다. 확인한 fail은 fail로 보존한다. 미실행이나 도움 후 통과는 무지원 독립 통과가 아니다.
구체적 강사 정답/모델은 17:25 이후 본인 여섯 명령 재현·도움 공개 뒤에만 연다. 모델 비교는 수업 종료 후의 후속선택연습이다. 이 조건은 자신의 src 읽기/작업을 막지 않는다.
두 동결 전 허용 자료는 independent-task.txt, 새 입력, 기존 src/계약과 본인 기록/테스트다.
도움은 handoff.txt [받은 도움]에 적는다. hint-assisted/answer-assisted를 실제 pass/fail/unknown과 구분한다.
도움을 숨기거나 자동 실패로 보지 않는다.
AI에 hints 폴더 전체를 첨부하지 않는다. 이 분리는 교육상 선택 장치이지 접근 통제가 아니다.
독립 전이는 새 합성 사례의 제한된 관찰이며 블라인드 능력 인증이 아니다.
실패/미실행 독립 관찰은 unknown과 다음 확인을 남긴다. 답안 도움 뒤에는 새 무도움 재시도를 계획한다.
