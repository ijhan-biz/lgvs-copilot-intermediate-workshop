========================
이 파일은 GitHub Copilot 자동 지침 파일이 아니다. 자동 로드/적용을 가정하지 않는다.
필요한 부분만 복사하고 contract.txt/해당 함수/필요한 테스트를 수동 선택 또는 첨부한다.
GitHub의 .github 지침 기능과 이 txt는 다르다. 이 실습에서는 자동 지침 파일을 만들지 않는다.
조직 정책에 맞는 모델만 사용한다. 강사용 자료/전체 저장소/기밀 자료를 첨부하지 않는다.
