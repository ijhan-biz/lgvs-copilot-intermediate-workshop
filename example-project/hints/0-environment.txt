지원 0 — 폴더와 실행 환경
VS Code와 터미널이 새 저장소 사본의 example-project 폴더만 가리키는지 확인한다.
교육 전만: 별도 연습 사본에서 npm run preflight와 readiness/task.txt를 수행한다.
preflight는 파일을 생성/수정하지 않는다. 수업은 git clone으로 새 사본을 받거나
GitHub Code → Download ZIP 소스 압축을 새 폴더에 모두 풀어 시작한다.
수업 npm test의 후보 정책 단언 실패와 Node22·import·명령 경로 문제를 구분한다.
현재 위치·명령·exit·오류를 기록하고 환경 문제면 코드 변경 전에 지원을 요청한다.
문제와 성공 기준 첫 파일 편집 전에 npm run baseline을 한 번 실행한다. 계획과 검증 기준 단계에서는 확인만 한다.
기존 .baseline은 보존한다. 거부 오류를 기록하고 사본/manifest를 확인한다.
삭제/덮어쓰기는 금지다. AI 정책상 불가/장애는 환경 테스트 실패와 다르다.
독립 전이는 본인 예측·이유·expectedIds 저장/동결과 최초 명령의 실제 outcome(pass/fail/unknown)·exit·출력 저장/동결을 모두 마칠 때까지 이 카드·AI·힌트·강사 도움·답안·고급 모델을 닫는다.
미실행/실행 불가는 outcome unknown·exit null로 동결하고 incomplete/HOLD 뒤 과정 도움을 연다. 확인한 fail은 fail로 보존하며 미실행/도움 후 통과는 무지원 독립 통과가 아니다.
