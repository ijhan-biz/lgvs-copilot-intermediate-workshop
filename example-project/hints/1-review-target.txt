지원 1 — 내가 검토하는 파일은 무엇인가?
npm run prepare:review는 최초 한 번만 실행한다. 기존 review 거부는 보호 기능이다.
npm run test:review 대상은 review/summarize-results.mjs다. src/summarize-results.mjs와 다른 대상이다.
templates/review-summarizer.mjs는 준비용 사본이다. 복구할 파일과 혼동하지 않는다.
정상 src를 덮어쓰지 않는다. 검토 파일 누락이면 준비 오류를 확인한다.
import/준비 오류를 의도된 계약 결함 검출로 부르지 않는다.
실제 명령/수/exit/실패 단언을 관찰하고 계약에서 본인 기대값을 먼저 적는다.
독립 전이는 본인 예측·이유·expectedIds 저장/동결과 최초 명령의 실제 outcome(pass/fail/unknown)·exit·출력 저장/동결을 모두 마칠 때까지 이 카드·AI·힌트·강사 도움·답안·고급 모델을 닫는다.
미실행/실행 불가는 outcome unknown·exit null로 동결하고 incomplete/HOLD 뒤 과정 도움을 연다. 확인한 fail은 fail로 보존하며 미실행/도움 후 통과는 무지원 독립 통과가 아니다.
구체적 강사 정답/모델 공개는 17:25 이후 본인 여섯 명령 재현·도움 공개 뒤다. 모델 비교는 수업 종료 후다.
