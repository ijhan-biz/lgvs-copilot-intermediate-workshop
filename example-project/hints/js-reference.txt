문법과 단언
import는 파일 최상위에 둔다. 제공 test/learner.test.mjs의 import를 중복하지 않는다.
  import assert from 'node:assert/strict';
  import { test } from 'node:test';
  import { summarizeTestResults } from '../src/summarize-results.mjs';
test('이름', () => { ... });는 테스트 하나다.
assert.deepEqual(actual, expected)는 배열·객체 내용을 비교한다.
assert.strictEqual(actual, expected)는 같은 값·같은 객체 참조를 확인한다.
assert.notStrictEqual(actual, expected)는 서로 다른 객체·배열인지 확인한다.
structuredClone으로 만든 비교용 사본은 입력 내용의 변경을 확인할 때 쓸 수 있다.
내용이 같은 사본과 원본 행은 같은 참조가 아니다. 후보 행을 깊은 복사로 바꾸지 않는다.
배열을 직접 정렬하거나 행의 status를 바꾸면 입력 보존을 어길 수 있다.
