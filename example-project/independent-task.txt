수정과 재검증 답안 없는 독립 전이 — 16:38–16:45, 설계7분
================================================
목적: 익숙한 결과를 복사하지 않고 승인된 요약 계약을 새 합성 검사 결과에 적용한다.
허용: 이 과제, data/transfer-results.json, 기존 src/계약(승인 C2-v2 포함), 본인 기록/테스트.
본인 예측·이유·expectedIds 저장/동결과 최초 명령의 실제 outcome(pass/fail/unknown)·exit·출력 저장/동결을 모두 마칠 때까지 AI·힌트·강사 도움·답안·고급 모델을 닫는다.
미실행/실행 불가는 outcome unknown·exit null로 동결하고 incomplete/HOLD를 남긴 뒤 과정 도움을 연다. 확인한 fail은 fail로 보존한다. 미실행이나 도움 후 통과는 무지원 독립 통과가 아니다.
기존 결함 소스를 감추지는 않지만 제공 해설이나 실행 결과를 기대값으로 복사하지 않는다.

입력은 data/transfer-results.json을 직접 읽는다. 빌드 선택은 test/transfer.test.mjs에서 확인한다.
정책은 failed·timed_out·not_run 후보 포함이다. not_run을 passed로 세지 않는다.
buildId/module/caseId의 전체 구분, 정확한 반복의 한 번 집계, 충돌 거부를 함께 적용한다.
모든 빌드의 행을 검증하고 선택 빌드만 센다. 후보와 모듈은 처음 등장 순서를 유지한다.
후보는 첫 원본 행 참조를 담는 새 배열이다. 입력 배열·행·옵션은 바꾸지 않는다.
정답 ID와 완성 코드는 제공하지 않는다. 기존 공개 예제의 ID나 실행 결과를 복사하지 않는다.
후보는 자문용이다. 실제 검사 재실행이나 출시 승인 권한은 없다.

입력을 읽고 계약에서 본인 기대값과 설명을 만든다.
1. 요약 함수나 전이 명령 실행보다 먼저 test/transfer.test.mjs의 expectedIds 바로 위 주석에
   본인 예측과 근거를 쓰고 저장한다. 따로 적는 양식은 없다.
2. test/transfer.test.mjs의 expectedIds = null 자리만 본인의 module/caseId 후보 배열로 작성한다.
   선택 빌드의 원본·고유·중복·상태별 건수도 손으로 대조하여 포함·제외 이유를 설명한다.
   실행값 자동 복사/후보끼리 비교로 독립 단언을 대체하지 않는다. 저장한다.
3. 요약 실행 전에 본인 예측/테스트를 먼저 고정한다. 따라하기 안내대로 실행 전 사본을 떠 둔다.
   기대값을 실행 결과에 맞춰 덮어쓰지 않는다. 나중 수정은 원래 예측과 이유를 보존한다.
4. 고정 뒤에만 npm run test:transfer를 실행한다. standalone 테스트1개다.
   null 자리의 최초 미작성 실패는 준비 상태이지 독립 시도/능력 실패를 관찰한 것이 아니다.
   learner4/공통16/최종 자가 검증과 결과 정리 여섯 명령에는 합치지 않는다.
5. 최초 명령의 실제 outcome/exit/출력·수·단언을 보존하고 고쳐 쓰지 않는다.
   예측/expectedIds만 고정한 단계에서는 도움을 열지 않는다. 두 동결 후 과정 도움을 연다.
   도움 상태와 실제 결과는 handoff.txt [받은 도움]에 따로 적는다.
   도움·시도: not-attempted / attempted-unassisted / hint-assisted / answer-assisted / incomplete.
   실제 결과: pass / fail / unknown. 미실행은 unknown이며 완료했다고 쓰지 않는다.
   두 동결 전후 힌트 도움은 hint-assisted, 답안/고급 모델 노출은 answer-assisted이며 시점을 남긴다.
   시도 없이 not-attempted, 무도움 시도는 attempted-unassisted, 실행/기록 미완료는 incomplete다.
   실패/미실행은 독립 역량 관찰 unknown으로 남기고 unknown/nextAction에 후속 확인을 적는다.
   fail을 unknown으로 숨기지 않는다. 도움 여부와 테스트 결과는 다른 관찰이다.

구체적 강사 정답/모델은 17:25 이후 본인 여섯 명령 재현·도움 공개 뒤에만 연다. 모델 비교는 수업 종료 후의 후속선택연습이다. 이 조건은 자신의 src 읽기/작업을 막지 않는다.
공개 저장소 배포본에는 강사용 참고 답안이나 복구 해설을 넣지 않는다.
도움 뒤 완료를 무도움 독립 숙달로 바꾸지 않는다. 새 합성 사례의 무도움 재시도를 계획한다.
