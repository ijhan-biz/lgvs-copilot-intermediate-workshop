GitHub Copilot 중급과정 — 학습자용 자료
==========================================

이 자료는 2026-10-28 09:00–18:00 운영 계획의 합성 데이터 실습 자료입니다.
공식 LG 또는 Microsoft 발행·인증·후원을 뜻하지 않습니다. 자료의 공유 범위는
소유자와 운영자가 확인해야 합니다. 별도 사용 허가나 라이선스는 제공하지 않습니다.

학습 목표
---------
하나의 JavaScript 프로젝트로 요청·계획·승인·작은 변경·검증·인계를 연습합니다.
가상 테스트 결과를 빌드별·모듈별로 요약하고 검토 후보를 정합니다. 실제 고객 데이터,
차량 코드, 자동 재실행, 출시 승인, 클라우드 배포는 다루지 않습니다. 후보는 사람의
검토 대상일 뿐입니다. 입력 자료의 passed/failed 건수와 node:test의 테스트 통과 수는
서로 다른 지표입니다. not_run은 passed가 아닙니다.

일곱 단계 (09:00 환경 확인, 17:50 마무리; 휴식·점심 별도)
--------------------------------------------------------
1. 09:20–10:10 원하는 결과·독립 기대값과 기준선 정하기
2. 10:20–11:10 필요한 자료와 수정 범위 고르기
3. 11:20–12:20 작은 변경·검증 계획 세우기
4. 13:20–14:50 승인된 후보 규칙 변경과 RED→GREEN 확인
5. 15:00–15:50 정상·경계·오류 및 별도 검토 코드 확인
6. 16:00–16:50 원인 복구, 16:38–16:45 독립 입력 최초 시도
7. 16:50–17:50 본인 재현·검토·README 인계

처음에는 failed만 검토 후보입니다. 13:45 사람의 승인 이후에만 timed_out과
not_run을 후보로 추가합니다. 상태별 입력 건수는 변하지 않으며 미실행을 통과로
간주하지 않습니다. AI가 제안해도 변경·명령 실행·승인을 자동화하지 않습니다.
도움받은 결과와 스스로 만든 최초 결과는 구분해 기록합니다.

시작과 파일
-----------
Node.js 22 이상, 조직이 허용한 VS Code와 Copilot 계정·정책을 확인합니다.
추가 패키지 설치는 필요하지 않습니다. participant-kit.zip을 완전히 압축 해제하고
PARTICIPANT-START.txt를 먼저 읽습니다. workbook.html은 브라우저로 열고
example-project 폴더만 VS Code에서 엽니다. 사전 연습은 별도 복사본에서
npm run readiness:check로 의도된 실패를 편집·저장·재검사하고, 실제 수업용은
ZIP을 다시 새 폴더에 풀어 시작합니다. 프로젝트에서 npm run preflight,
npm test를 확인하고 첫 편집 전에 npm run baseline을 실행합니다.
교육내용-쉬운설명.docx/.pdf는 쉬운 과정 개요이며 ZIP에는 포함되지 않습니다.

수업 배포용 ZIP에는 빈 work-record.json이 들어 있습니다. 저장소를 직접 복제했다면
preflight와 처음 검사를 확인하고, 어떤 파일이든 처음 수정하기 전에
npm run baseline으로 기준 사본을 남깁니다. 그다음
example-project/work-record.template.json을 같은 폴더의 work-record.json으로
복사해 기록합니다. 개인 기록 파일은 Git에서 제외되며 공개 저장소에 올리지 않습니다.

워크북의 JSON 내보내기·가져오기로 본인 기록을 보관합니다. 공개 저장소에
학습자 개인 기록이나 비밀을 올리지 마세요. 자료·출처도 직접 확인하세요.
상세 진행·여섯 재현 명령은 PARTICIPANT-START.txt와 workbook.html을 따릅니다.

강사용 상세 진행안·정답·모델 구현·후속 비교 실험은 게시하지 않습니다.
강사가 독립 시도와 최초 실행 결과, 본인의 여섯 명령 재현과 도움 공개를
확인한 뒤 17:25 이후에만 참고 답안을 열어 줍니다. 후속 선택 실습은
수업 종료 후 별도로 공유되며 이 다운로드의 일부가 아닙니다.
